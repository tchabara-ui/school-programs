```
「わからない」と言えることが、リーダーシップだった

1泊2日のチームビルディング研修にて。

靴紐を結び合って全員でゴールを目指す「多人数多脚」。
目を閉じたまま指示だけで紙を折る「目隠しワーク」。

どちらのワークでも見えてきたのは、
同じ結論でした。

✓ 分かったふりをする上司より
✓ 「教えて」と言えるリーダーの方が
✓ 実は信頼される

焼肉を焼きながら気づいたという話も印象的でした。
「じわじわ汁が浮かんできて、あ、今裏返しのタイミングだ」
1人でやってると気づかないことも、
誰かに教えようとした瞬間に見えてくる。

観察力。想像力。意図。
体験から学ぶって、そういうことなのかもしれません。

2日間の最後、参加者が描いた小さな絵の裏に
書き込んだのはこんな言葉たち。

・名前を呼ぶ
・褒める
・ありがとうを言う
・目を見て笑顔で挨拶する

大きな改革じゃなくていい。
小さな積み重ねが、チームを変えていく。

あなたのチームには、
「わからない」と言える空気、ありますか?
```
