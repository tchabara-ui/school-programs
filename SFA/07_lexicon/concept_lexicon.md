### Prototype Kitchen

Prototype Kitchenとは、現場で実践する前に、新しい行動・対話・リーダーシップ・チームのあり方を
安心して試作し、フィードバックを受けながら磨き、現場へ持ち帰るための学習環境である。

料理人が、お客様に料理を出す前に、厨房で試作し、味見し、フィードバックを受けて改善するように、
研修では現場に持ち帰る行動を試作する。

### 啐啄同時（そったくどうじ）

禅語。ひなが卵の内側から殻をつつく音（啐）と、親鳥が外側から殻をつつく音（啄）が
同時であることに由来し、学び手の準備が整うタイミングと、支援者が働きかけるタイミングが
一致することの重要性を指す。ファシリテーションにおける「介入のタイミング」を語る際の中核概念。

- 初出セッション:（未記入 / 該当セッションIDを追記）
- 関連タグ: `【啐啄同時】【介入】`

## タグ定義

各発言・要約に対して、SFA Session／AI分析／名言集の作成時に付与するタグ。
検索・分析・研究利用のためのインデックスとして機能する。

| タグ | 意味 |
|---|---|
| 【問い】 | ファシリテーターが投げかけた問い |
| 【フレーミング】 | 意味づけ・視点転換を促す言葉 |
| 【比喩】 | 概念を伝えるための比喩・メタファー |
| 【ユーモア】 | 場を和ませる・緊張を解くユーモア |
| 【心理的安全性】 | 安心して発言・挑戦できる場づくりに関わる場面 |
| 【組織開発】 | 個人の学びが組織・チームに接続する場面 |
| 【感情喚起】 | 参加者の感情が動いた場面 |
| 【現場転移】 | 学びを現場に持ち帰る具体像が語られた場面 |
| 【リーダーシップ】 | リーダーシップのあり方に関する発言・観察 |
| 【学習理論】 | 学習理論・成人学習に接続できる場面 |
| 【介入】 | ファシリテーターの意図的な働きかけ |
| 【観察】 | ファシリテーターによる場・参加者の観察記録 |
| 【参加者反応】 | 参加者の反応（発言・表情・態度の変化） |
| 【名言】 | 引用価値の高い発言 |
| 【Prototype Kitchen】 | Prototype Kitchen概念に関連する場面 |
| 【啐啄同時】 | 啐啄同時の概念に関連する場面 |
| 【Iメッセージ】 | 主語を「私」にして自分の気持ちを伝える、相手を責めないフィードバック技法に関連する場面 |
