```
今日は八百一さんの店舗リーダー研修に、朝9時から夕方6時過ぎまで、丸一日ご一緒させていただきました。

朝は円になって、トーキングオブジェクトを回しながらのチェックインから。今年初めて参加する方、前回のグループから離れて少し緊張している方、体調を崩して久しぶりに現場に戻ってきた方。それぞれの今の状態を、そのまま言葉にしてもらうところから一日が始まりました。

その後は、体を動かすストレッチ、久しぶりに再会した友人役になりきって挨拶を交わすロールプレイ、紙風船を潰さないように押し引きのバランスを探るペアワーク。「めっちゃ潰れてるやん」と笑い合いながら、リーダーシップとフォロワーシップの力加減を、頭でなく体で確かめていく時間でした。

午前の後半には「聞く」ことについてもお話ししました。部下から「もうこの担当をやりたくないです」と言われたとき、つい口にしてしまう言葉があります。理由を問いただす、安心させる、正しさを説く。どれも一見悪気はないのに、実は相手が話し始めた瞬間に、口を閉じさせてしまう応答なんです。私自身、経営者として天狗になっていた時代、業務委託先の社員がほぼ全員辞めてしまいそうになった危機がありました。ダメ元でアクティブリスニング、ただ黙って聞くということを試したとき、最後まで残ってくれたメンバーが「僕はここに残った方が、自由にやりたいことをやらせてくれる気がするんです」と、自分で決めて残ってくれました。聞くって、本当にパワフルなんだと、あの時思ったんです。

午後は目標設定の話から。「何のためにこれをやるか、教えてください」と、フラフープを運ぶゲームの前にチームに問いかけます。やり方を先に決めてしまうと、目的を見失う。これは現場でも同じです。品出しの時間を「10%削減する」という目標を、リーダーが押しつけるのではなく本人が自分で決める。そうやって初めて、人は本気で動く。そんな実例も交えながらお伝えしました。

そして一日の締めくくりは「マシュマロリバー」。一人一枚のマットを重りにして、常に二枚以上を誰かの足や手の上に乗せておかないと、川に流されてしまうというルールです。

途中、キムさんが「火傷」役でリタイアするアクシデントが起きました。それでもチームの動きは止まりませんでした。誰かが残ったマットを拾い、声をかけ合いながら、少しずつ渡っていく。タイムリミット30分に対して、結果は29分47秒。ギリギリのところで、全員が渡り切りました。

終わった瞬間、あちこちから歓声が上がって、正直「声が重なって聞こえていないんじゃないか」と少し心配したくらいです。でも振り返ってみると、参加された方々は「自分だけの判断で進むのではなく、聞いて、周りに確認して、一歩を踏み出す」ことをちゃんとやっていたんです。

これは特別な能力ではありません。誰が仕切るかではなく、誰かが「ここです」と声を出したときに、周りが「そうか、ありがとう」と受け取れるかどうか。その積み重ねが、チームの一体感をつくっていきます。

私自身、経営者として天狗になっていた時代がありました。誰が自分に挨拶してくるかを気にして、イライラしていた自分がいたんです。あるとき、自分から挨拶する側に回ってみたら、見える景色が変わりました。天気を決めているのは、結局いつも自分だったんですね。

指示すること、正しさを説くこと。それよりも先に「聞く」こと。今日一日、八百一の皆さんと過ごしながら、あらためてそのことを実感しました。

明日はまた、新しいドラマが生まれるはずです。

みなさんの職場では、最近「聞いて、動く」場面がありましたか？ それはどんな瞬間でしたか？
```
